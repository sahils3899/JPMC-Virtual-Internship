This repository contains my completed tasks for the J.P. Morgan Chase Software Engineering Virtual Experience Program hosted on Forage. The internship simulates real-world work done by JPMC’s technology team, focusing on financial data analysis, data visualization, and frontend development for trader dashboards.

The project demonstrates practical skills in:
	•	Financial data processing
	•	Python programming
	•	Data visualization
	•	Frontend development using Perspective
	•	Debugging and unit testing

The virtual internship involves working with stock price data feeds, analyzing financial data, and building interactive visual dashboards for traders.  ￼
